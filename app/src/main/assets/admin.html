অ্যাপ লোগো ও ছবি সেটিংস (App Logo & Image Settings)

এখানে আপনার অ্যাপের বিভিন্ন জায়গার লোগো ও ছবি পরিবর্তন করতে পারবেন। প্রতিটি ইনপুট বক্সের নিচে আলাদা 'সেভ করুন' বাটন রয়েছে।

১. অ্যাপের মূল হেডার লোগো (Header Logo)

ইউজার অ্যাপের একদম উপরে হেডার বা নেভিগেশন বারে যে মূল লোগোটি থাকে।

২. অ্যাপ লোডিং এনিমেশন লোগো (Loading Screen Logo)

ইউজার অ্যাপে ঢোকার সময় যে ফুলস্ক্রিন সাদা লোডিং বা স্প্ল্যাশ স্ক্রিন আসে, তার মাঝখানের ঘুরন্ত লোগো।

৩. লগইন পেজ লোগো (Login Page Logo)

ইউজার যখন অ্যাপে লগইন বা সাইনইন ডায়ালগে থাকে, তখন উপরে যে লোগোটি দেখায়।

৪. টোস্ট ও নোটিফিকেশন পপ-আপ লোগো (Toast Dialog Logo)

প্যাকেজ বা ইউআইডি না দিলে নিচে যে নোটিফিকেশন মেসেজ ভেসে ওঠে, তার সাথে যে লোগোটি আসে।

৫. পুশ নোটিফিকেশন লোগো (Push Notification Logo)

এডমিন থেকে ইউজারদের ফোনে পুশ নোটিফিকেশন পাঠালে নোটিফিকেশনের সাথে যে লোগোটি দেখায়।

৬. বিকাশ মোডাল ও পেমেন্ট লোগো (bKash Payment Logo)

অ্যাড মানি পেজে বিকাশ পেমেন্ট মোডাল বা অটো পেমেন্টে যে বিকাশ লোগো দেখায়।

৭. নগদ মোডাল ও পেমেন্ট লোগো (Nagad Payment Logo)

অ্যাড মানি পেজে নগদ পেমেন্ট মোডাল বা অটো পেমেন্টে যে নগদ লোগো দেখায়।

অ্যাপ টেক্সট ও বাটন সেটিংস (App Text & Button Settings)

এখানে ইউজার অ্যাপের বিভিন্ন লেখার বিষয়বস্তু, বাটন টেক্সট ও নোটিশ পরিবর্তন করতে পারবেন। প্রতিটি ইনপুট বক্সের নিচে সেভ বাটন দেওয়া আছে।

১. প্লেয়ার আইডি ইনপুট বক্সের প্লেসহোল্ডার

টপআপ পেজে Player ID লিখার বক্সে হালকা রঙের যে টেক্সট লেখা থাকে (যেমন: Enter Player ID)।

২. 'আইডির নাম চেক করুন' বাটন টেক্সট

টপআপ পেজে প্লেয়ার আইডির নাম অটো চেক করার বাটনের টেক্সট।

৩. 'এখনই কিনুন' (Buy Now) বাটন টেক্সট

টপআপ পেজে প্যাকেজ কেনার মূল বাটনের টেক্সট (যেমন: Buy Now / এখনই অর্ডার করুন)।

৪. বটম নেভিগেশন ১ - হোম বাটন টেক্সট

ইউজার অ্যাপের একদম নিচে প্রথম বাটনটির নাম (যেমন: Home / হোম)।

৫. বটম নেভিগেশন ২ - টিউটোরিয়াল বাটন টেক্সট

ইউজার অ্যাপের একদম নিচে দ্বিতীয় বাটনটির নাম (যেমন: Tutorial / ভিডিও)।

৬. বটম নেভিগেশন ৩ - অ্যাড মানি বাটন টেক্সট

ইউজার অ্যাপের একদম নিচে তৃতীয় বাটনটির নাম (যেমন: Add Money / ওয়ালেট)।

৭. বটম নেভিগেশন ৪ - হিস্ট্রি / মাই অর্ডার টেক্সট

ইউজার অ্যাপের একদম নিচে চতুর্থ বাটনটির নাম (যেমন: History / মাই অর্ডার)।

৮. বটম নেভিগেশন ৫ - একাউন্ট বাটন টেক্সট

ইউজার অ্যাপের একদম নিচে পঞ্চম বাটনটির নাম (যেমন: Account / একাউন্ট)।

৯. টিউটোরিয়াল পেজ হেডিং (Tutorial Section Title)

ইউজার অ্যাপের ভিডিও টিউটোরিয়াল সেকশনের উপরের বড় হেডিং টেক্সট।

১০. প্যাকেজের একদম নিচের নোটিশ টেক্সট (Rules Notice)

প্যাকেজের একদম নিচে 'নোটিশ:' এর পাশে ৩ডি কার্ডে স্পষ্ট কালো রঙের যে নোটিশ লেখাটি দেখাবে।

কিভাবে কাজ করবে?

"Show Popup" বাটনটি চালু রাখলে ইউজাররা অ্যাপে ঢুকলেই একটি পপআপ মেসেজ দেখতে পাবে। ইমেজ এবং লিংঙ্ক সেট করা থাকলে ইমেজে ক্লিক করলেই ইউজার সেই লিংকে চলে যাবে (ভিডিও বা অফার)।

Firebase Config Editor (ফায়ারবেজ কনফিগারেশন)

আপনি সরাসরি আপনার ফায়ারবেজ কনসোলের const firebaseConfig = { ... }; কোড কপি করে নিচের বক্সে পেস্ট করে সেভ করুন।

নির্দেশিকা (How to use)
  • 1. ফায়ারবেজ প্রজেক্ট সেটিংস (Project Settings -> General -> Web App) থেকে firebaseConfig কোডটি কপি করুন।
  • 2. সম্পূর্ণ কোডটি হুবহু বাম পাশের বক্সে পেস্ট করে Save Firebase Config বাটনে ক্লিক করুন।
  • 3. ইউজার অ্যাপ এবং এডমিন প্যানেল সাথে সাথে নতুন ফায়ারবেজ ডাটাবেসের সাথে যুক্ত হয়ে যাবে।
